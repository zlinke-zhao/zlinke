## 一句话总结

扣子Coze是国内最活跃的零代码AI Agent搭建平台，适合非技术团队快速搭工作流、做自媒体和接微信/飞书生态；不适合对数据主权极度敏感、或需要深度私有化定制的团队。

## 核心功能评测

### 1. 项目空间（多Agent协作）—— ⭐⭐⭐⭐⭐

这是 3.0 的基石能力，也是扣子区别于多数竞品的核心。3.0 之前每个 Agent 孤立运行，复杂项目只能靠来回复制上下文；3.0 引入「项目空间」，在一个项目里创建多个职能 Agent（如调研、文案、设计），通过 @ 派活、共享同一上下文与文件系统，像真实工作群一样接力推进。

实测体验：创建项目 → 添加 Agent → 上传资料 → 分配任务，流程顺滑，界面接近简化版飞书文档。一个内容项目里 @文案写初稿、@审核查错、@配图出封面，约 15 分钟凑齐一篇公众号所需的全套素材。局限是跨项目不共享上下文，长链路里一旦上游 Agent 输出偏差，下游会基于错误输入继续执行，需要人工在关键节点把关。

### 2. 本地Agent一键接入（coze-bridge）—— ⭐⭐⭐⭐⭐

这是最让我惊喜的能力。通过 coze-bridge 小服务，系统能自动识别本机安装的 Claude Code、Codex CLI、OpenClaw，无需手动配 API 环境变量和端口，点连接即可把本地命令行 Agent 拉进项目工作台，和云端 Agent 协同。本地代码执行、文件操作与云端搜索、写作在同一项目里无缝衔接，且本地数据不必上云。代价是免费版仅能连 1 个、进阶版 1 个、高阶版 3 个、旗舰版 10 个，尊享版与团队/企业版不限——重度技术团队想多接几个本地 Agent 得上高阶及以上。

### 3. 三端协同与云Agent —— ⭐⭐⭐⭐

网页端、桌面端（2026年8月上线）、手机 App 三端实时同步。最实用的场景：电脑上建好编程项目，通勤用手机 App 查看进度并 @Agent 继续推进，桌面端 Agent 还能被授权读取本地文件远程干活。云端 Agent 跑在扣子提供的云电脑/云手机上，7×24 在线，适合定时抓取、监控、无人值守自动化。需注意云端 Agent 目前主要用豆包等内置国产模型，不吃本地算力。

### 4. 垂直技能包与编程/视频项目 —— ⭐⭐⭐

内置投资、自媒体、调研、法务、科研、电商六大行业技能包与职业模板，一键加载专家级 Agent；另有编程项目（code.coze.cn，对话式开发网页/小程序）和视频项目（搭载 Seedance 2.5，剧本到成片一站式，可直接导出剪映工程）。自媒体技能包确实能跑通选题→写稿→配图→排版；但法务、投研类深度有限，复杂专业场景仍需二次定制。

## 优势与短板

### 四大优势

1. **范式领先的AI团队协作**：从「一个人对一个AI聊天」升级到「人指挥一支AI军团」，在竞品还卷单助手对话质量时，扣子已卷到多Agent协作，护城河短期难填。
2. **零代码做到极致**：拖拽工作流节点 + 可视化编排，非技术用户打开浏览器就能用，对比 Dify 需配模型环境、LangFlow 需 LangChain 基础，扣子是真·开箱即用。
3. **字节生态不可复制**：微信、飞书、抖音、豆包、剪映原生打通，Agent 搭好一键发多平台，流量闭环完整，这是任何竞品抄不走的渠道优势。
4. **本地Agent接入兼顾隐私**：coze-bridge 把 Claude Code/Codex/OpenClaw 拉进项目，本地代码与文件不必上云，技术团队能用上云端编排又不丢本地能力。

### 四大短板

1. **免费版几乎不能干活**：0 积分意味着视频、云手机、最新大模型等重资源功能全锁，基础对话也要靠每日登录赠送额度，想认真用必付费。
2. **闭源SaaS限制创造力**：不买企业版不能私有化、不能自定义模型管线，黑盒行为让技术型用户受限；自托管只能另装 Coze Studio，体验明显弱于托管版。
3. **数据主权顾虑真实存在**：字节出海背景让政府、金融、医疗等强合规行业天然警惕，这类用户应优先 OpenClaw 等自托管方案。
4. **长链路不稳、调试更难**：多Agent接力时单点幻觉会放大错误，调试一个跑偏的多步计划比修单个工作流更费劲（36氪实测也提到工作流偶发中断、复杂长指令误读）。

## 最终推荐

### ✅ 强烈推荐

- **中小企业主/创业团队**：零门槛搭AI工作流，一个人带多个Agent，月付 ¥39.9 顶半个初级员工。
- **自媒体/内容创作者**：行业技能包 + 多Agent 配合做选题→写稿→配图→排版，15分钟出一套素材。
- **独立开发者**：用扣子串起 Claude Code + Codex 形成研发流水线，本地数据不泄漏。

### ⚠️ 谨慎观望

- **数据安全敏感型企业（金融/政务/医疗）**：等企业私有化方案成熟，或直接上 OpenClaw 自托管。
- **重度定制需求者**：闭源SaaS限制大，深度定制会被逼向开源方案。

### ❌ 不推荐

- **纯技术信仰派**：黑盒限制会劝退，直接上 OpenClaw 或 Dify。
- **只想聊聊天写文案的轻度用户**：扣子是「组装乐高」，比直接开 ChatGPT 门槛高，杀鸡用牛刀。

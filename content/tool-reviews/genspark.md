## 一句话总结
Genspark 适合想把「搜索—研究—做 PPT/表格—打电话」打包给一个订阅搞定的人；不适合追求可预测账单、强隐私合规、或要把关键流程长期绑定在一家厂商的人。

## 核心功能评测

**1. Super Agent 与多智能体混合架构 — 4.5/5**
Genspark 不是聊天机器人，而是把目标拆成步骤、为每个步骤选派最合适的前沿模型与工具、最后经反思环节合并结果。这种「Mixture-of-Agents」让它在单一订阅里调用 70–80+ 模型。实测下来，广度是它最强的卖点：一句话就能产出带引用的研究页、完整幻灯片、分析过的表格、网站甚至电话。短板是底层模型会动态切换，Reddit 有用户反映切换后质量飘忽。

**2. Sparkpages 与深度研究 — 4.0/5**
Signature 功能 Sparkpages 会把搜索结果直接做成可交付的动态报告页（图表、时间轴、对比表、甚至一键拨号按钮），而非一堆链接。深度研究能力被普遍认可为「够好的起点」，但日本 AI 咨询公司 TIMEWELL 在 2026-02（beta 期）实测发现它会编造营收数据与营业利润率、混用别家专利。官方称 2026-07 重构了 Super Agent，但社区 2026 年仍有幻觉反馈，关键数字务必复核。

**3. AI Slides / Sheets / Docs 成品工厂 — 4.3/5**
这是 Genspark 口碑最稳的一块。AI Slides 被 Reddit 与多个独立评测称为「市面上最好的做 PPT 工具之一」，可导出 PDF/PPTX/Google Slides；有顾问称「打开改两页就能发」。Sheets 评价较弱，有用户反映公式引用错列。整体看，做「研究→成品」比纯对话工具省大量时间。

**4. Call For Me 真实电话 — 4.0/5**
经 Twilio Programmable Voice，Genspark 能真拨商家电话完成预约/问询并回传录音与摘要，自称 40+ 国家、94.3% 呼叫成功率。实测多为低 stakes 场景（停车询问、餐厅订位）有效，复杂谈判不推荐。每通固定约 500 积分，是少数把 Agent 落到物理世界的动作。

**5. Genspark Claw + Cloud Computer — 4.2/5**
Workspace 3.0 的核心：每位用户获得一台专属、常驻、隔离的云 VM（Cloud Computer），AI 员工 Claw 在上面独立干活，经 WhatsApp/Telegram/Teams/Slack 发消息即驱动，还能接 20+ 办公应用做 Workflows。架构上用「隔离而非索取桌面权限」保隐私，是区别于本机执行型桌面 Agent 的独门路线。

## 优势与短板

**优势（展开）**：①广度无敌——一个订阅覆盖 70–80+ 模型与 80+ 工具，对「想少开几个会员」的用户极具吸引力；②AI Slides 真能打，成品质量与可编辑性获社区普遍好评；③Call For Me 是差异化杀器，把 Agent 从屏幕延伸到真实电话；④Claw+Cloud Computer 的「隔离云 VM + IM 原生」架构在桌面 Agent 里独树一帜；⑤免费档真能用，加微软合作背书，企业渗透快（6,000+ 客户自称）。

**短板（坦诚）**：①积分账单是头号槽点，不可预测、不滚存、失败也扣，Trustpilot 约 2/5 集中在扣费与退款；②口碑两极——Google Play 4.5 星（约 8.9 万评价）与 Trustpilot 负面形成鲜明反差；③研究幻觉风险需人工复核关键数字；④隐私安全有硬伤：VerifyWise 透明度 C 级、Genspark Browser 仅拦 7% 钓鱼站（LayerX）、Android 端曾曝 CVE-2026-12190 鉴权绕过；⑤促销 12/31/2026 到期后的条款不确定性，是企业绑定的隐患。

## 最终推荐

**推荐使用的人**：①个人创作者/营销人，每周要产出大量 PPT、报告、内容变体，且不想维护多个订阅；②研究者/分析师，需要把「查资料」直接变成「带引用的交付页」；③小团队，想用 Claw + Workflows 把重复办公动作（跟进、排会、打电话）自动化；④已是微软 365 用户，看重 Agent 原生嵌入 Office 的便利。

**不建议使用的人**：①对账单可预测性要求高的企业财务/采购，积分制会让预算失控；②强隐私/合规行业（医疗、金融）用户，当前透明度与安全 posture 不支持；③要把核心业务流程长期绑定在某平台的公司，12/31/2026 后条款变动是真实风险；④只做幻灯片这一种需求的人，单买 Gamma/Canva 更专精更便宜。

**实操建议**：先用免费档跑 2–3 个真实任务，实测自己的积分消耗曲线；订阅前确认 12/31/2026 促销到期后的实际费率；研究类输出务必人工复核关键数据；不要把不可替代的工作流只押在 Genspark 一家。整体评分 4.2/5——产品力领先、野心十足，但商业化与信任建设仍拖后腿。

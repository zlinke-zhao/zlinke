## 一句话总结

实在Agent 是实在智能（Intelligence Indeed）推出的企业级通用智能体，它最硬的底牌不是聊天，而是**「像真人一样操作电脑」——基于自研 TARS 大模型 + ISSUT 屏幕语义理解 + RPA 三位一体，不依赖任何 API，就能在 ERP/CRM/微信/钉钉 等任意有界面的软件上把一句话变成真实执行的自动化流程**。**适合有跨系统、长链条、老旧系统搬运需求的中大型企业（金融/政务/制造/电商），但个人轻量玩家和小团队会觉得它的企业级架子和销售定制报价不够「开箱即用」。**

## 核心功能评测

### 1. ISSUT 智能屏幕语义理解（眼睛） ⭐⭐⭐⭐⭐（5/5）

这是实在Agent 真正的护城河，也是它和「传统 RPA」「普通桌面 Agent」的本质区别。传统 RPA 靠 XPath / 坐标定位元素，页面一改版脚本就崩；ISSUT（Intelligent Screen Semantic Understanding Technology）通过计算机视觉对屏幕做像素级语义解析，**像人眼一样识别「什么是输入框、什么是确定按钮」**，不记坐标、不依赖 API。

实测反馈里有个很能说明问题的细节：某系统弹出「版本更新」干扰弹窗，Agent 自主识别并关闭后继续任务（hqwc.cn 实测）。对 ERP、C/S 架构老系统、信创环境下的国产应用，这种「人眼看得到就能操作」的能力意味着极低的维护成本——官方称采用 ISSUT 的 Agent 自愈率已提升至 95% 以上。

### 2. TARS 垂直大模型 + 任务拆解（大脑） ⭐⭐⭐⭐☆（4.5/5）

TARS 是实在智能自研、专门面向企业业务流程微调的多模态垂直大模型，已完成国家网信办模型+算法双备案。它负责把一句口语（如「帮我把这个表格按客户名分别存到不同文件夹」）自主拆成登录系统→筛选→查询→生成→发送的步骤序列。

官方公布的可验证数据：任务步骤拆解准确率 84.16%（同场景 GPT-4 为 74.26%），动作映射准确率 86.87%，综合得分 87.24%（DeepSeek-R1 为 84.72%），测试覆盖 1000+ 企业软件、10000+ 常用场景。扣分点在于：在单次任务步骤超过 50 步且网络极不稳定的极端情况下，官方建议开启「检查点」机制维持 95% 以上稳定性——说明超长链路仍有天花板。

### 3. RPA 超自动化执行（双手） ⭐⭐⭐⭐⭐（5/5）

TARS AI 元素定位让执行层即便元素低级属性全部改变，只要功能不变就能命中。配合 RPA 模拟键鼠，Agent 能在跨系统间点击、输入、上传、下载。最新 v7.3.7 还把 RPA 元素编辑器升级为「AI 增强定位」，流程包加载提速 30%+、元素拾取提速 72%。实测量化对比：单笔操作耗时从人工+RPA 的 480 秒降至 45 秒（提效 90%），出错率从 5.2% 降到 0.1% 以下，月度技术支持从 2 次降到 0 次。

### 4. 无界模式：微信/钉钉/飞书远程指挥 ⭐⭐⭐⭐☆（4.5/5）

这是 2026 年桌面 Agent 的兵家必争之地。实在Agent 从 v7.3.5（2026-06-23）起把 TARS 无界模式全面打通微信、企业微信、钉钉、飞书——手机发一条微信，电脑自动完成 Excel 报表、查 ERP、发邮件并回传进度。本地文件/图片可直接读取解析，无需上传云端，兼顾隐私与准确。扣半星是因为：无界模式依赖扫码授权与后台常驻，对纯个人用户而言配置链路比消费级竞品略重。

### 5. 企业级安全与全栈信创适配 ⭐⭐⭐⭐⭐（5/5）

实在Agent 原生支持国产芯片（鲲鹏、飞腾）与国产操作系统（麒麟、统信 UOS、鸿蒙），数据库适配达梦、金仓，全栈信创可跑在单张 T4 / 国产 AI 卡上。对金融、政务、央国企这种「数据不出内网、强合规审计」的场景，这是它相对海外 RPA（如 UiPath）和纯云端 Agent 的决定性优势。流程运行中还能生成全量可审计日志，满足国内合规审计要求。

## 优势与短板

**优势（展开）**
- **OSWorld 双冠是硬通货**：2026-07-27 以 90.2% 登顶 OSWorld 总榜与 Agentic Framework 分榜，是全球首个突破 90% 的 Computer-Use Agent，领先第二名 6.6 个百分点；细分里系统底层操作 24 个任务 100% 满分、GIMP 图像处理 26 任务完成 24 个（92.3%）。这是目前国产智能体在国际基准上最拿得出手的成绩。
- **ISSUT 把「脆弱的 RPA」变成「抗变的 Agent」**：不依赖坐标和 API，按钮移动、颜色变化仍能基于语义命中，老旧系统和信创环境是它反复被媒体引用的差异化场景。
- **落地规模经得起追问**：华电财务共享中心、裕同包装（年省 7800+ 人天）、某客户日报场景 180 分钟→10 分钟（提效 94%）等案例，证明它不是 PPT 级 Demo。

**短板（坦诚）**
- **定价不透明**：没有公开的自助下单页或按席 API 价，企业版必须走销售报价，中小团队难快速估算 ROI。
- **独立口碑难交叉验证**：RECATOOLS 给出 6/10（能力 6.5 / 性价比 5.5 / 易用 6），并指出 G2、Capterra、Trustpilot 均无条目，中文评测多为厂商稿，真实 NPS 存疑。
- **命名混淆风险**：务必区分「实在Agent（实在智能）」与字节跳动开源的「Agent TARS / UI-TARS」——同名不同公司，选型时认准 Intelligence Indeed。

## 最终推荐

**强烈推荐给：**
- 金融、政务、运营商、大型制造等**有老旧系统 / 无 API 接口 / 强信创合规**需求的企业，实在Agent 的 ISSUT + 私有化部署几乎是为这类场景量身定做；
- 已被重复跨系统搬运、对账、报表压得喘不过气的**中后台运营 / 财务 / 供应链团队**，先用社区版免费验证一个高频场景，再谈采购。

**谨慎或暂不选：**
- 纯个人玩家、小团队只想「手机指挥电脑干点轻活」——它的企业级控制台、销售定制报价和 SOP 梳理门槛偏高，同站里的 Kimi Work / AutoClaw / QoderWork / KroWork 更轻快；
- 极致追求定价透明、想今天下单明天就用、且主要场景在标准化 Web 自动化的电商团队——影刀 RPA 的模板与性价比可能更顺手。

**上手建议**：先下社区版（免费，注册赠 5000 资源点），挑一个「每天重复、有图形界面、逻辑明确」的流程（如下载未发货订单并催单）跑通，验证 ISSUT 在你真实系统上的稳定性，再决定是否进入企业版商务谈判。

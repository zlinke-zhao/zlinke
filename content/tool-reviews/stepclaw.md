## 一句话总结

StepClaw（阶跃龙虾）是阶跃星辰把 OpenClaw 深度封装后的桌面级 Agent，它解决的核心问题只有一个：**让不会敲命令行的普通人也能养一只龙虾**。双击安装、扫码领养、微信发消息遥控电脑，配上 5000+ 技能的水产市场和一只会随 token 消耗进化的桌宠，它把「养 Agent」这件事做成了大众消费品。**适合被原版 OpenClaw 的环境配置劝退、又想要 7×24 后台助理的国内办公人群，尤其是常做文件归档、定时汇总、资料搜集这类流程确定的重复劳动的人；但如果你的主要诉求是写代码、跑复杂多步开发任务，或者对模型账单极度敏感，它目前还不是最优解——第三方横评对它编程能力的评价是直白的「弱」，而一个定时日报任务单次对话就能烧掉百万级 token。**

## 核心功能评测

### 1. 零门槛安装与领养 —— 5/5

这是 StepClaw 最没有争议的强项。原版 OpenClaw 的劝退清单很长：Node.js 22+ 环境、环境变量、API Key、Skills 手动安装，没有半天搞不定。StepClaw 的路径是：去官网下载「阶跃 AI 桌面伙伴」→ 双击安装 → 在桌面伙伴里点一下「领养」，完成。无需服务器、无需命令行、无需 Docker、无需自备 API Key。

一个容易被忽略但很加分的细节：**安装过程中它可以直接同步你电脑里已经存在的 OpenClaw 配置**，老用户迁移不用从头折腾环境。装好后桌面侧边常驻一个悬浮入口，点开就是类似聊天工具的输入框，任务推进进度实时可视化。

### 2. 水产市场技能生态 —— 4.5/5

生态是阶跃这套方案真正的差异化。据中国日报财经频道 2026-03-19 报道，水产市场已有 5000+ 创作者入驻、5000+ 精选应用资源，涵盖 Skill、插件、触发器、频道、经验包五种资产类型。

值得注意的是安装方式很符合 Agent 时代的逻辑：你不需要自己研究细节，**把水产市场页面上那行安装命令复制给 StepClaw，让它自己去装就行**。更进一步，龙虾还能自动复盘能力缺口、主动搜索并补齐短板。

触发器是这个生态里被低估的模块。有实测者装了一个叫「自动看门狗」的触发器，它会按设定的心跳周期（默认约 30 分钟）自动巡检 Cron 作业、系统进程、磁盘使用与 API 可用状态，发现之前部署的项目异常后自动重启服务并复检至恢复正常。

扣分项在质量控制：**技能质量参差不齐，实测建议先装官方精选**。

### 3. 五端 IM 远程指挥 —— 4.5/5

StepClaw 是最早接入微信的龙虾之一，目前微信、飞书、企微、钉钉、QQ 五端全通。装好客户端后扫码绑定微信，通讯录里会多出一个叫「小龙虾」的联系人。

有实测者给出了三个具体场景的结果：让它整理桌面文件，几十个杂乱图标一分钟不到按类型归好文件夹；让它搜行业政策整理摘要，它自己开浏览器搜了几个网站提取关键信息生成文档存到桌面；让它做简单 PPT，它打开 WPS 套模板填内容，基础框架够用、改一改能交。这个能力边界描述得相当诚实——**它交付的是「改一改能用」而不是「直接能用」**。

### 4. 个性化与养成体验 —— 4.5/5

这是 StepClaw 跟其他厂商路线分叉最明显的地方。你可以通过编辑灵魂模板（SOUL.md）赋予龙虾独特性格，社区里有大量人设模板可选。有用户给两只龙虾设了完全相反的人设：一只极端效率主义、只讲结果不讲情绪；另一只偏质疑型，接到指令先做一轮头脑风暴、连环追问、带点对抗思维。

外观上可以装桌宠皮肤变成趴在桌面的像素小龙虾，还有像素办公室、进度看板等可视化界面，桌宠会随 token 消耗从粉红小龙虾成长为龙虾王，有 10 款皮肤、排行榜与 PK 战斗。**你还能一次养很多只虾，每只的上下文记忆彼此隔离互不干扰。**

这看似是花架子，实际解决的是留存问题：跟一个有形象的 Agent 互动，心理门槛比面对冷冰冰的对话框低得多。

### 5. 编程与复杂任务执行 —— 2.5/5

这是必须说清楚的短板。SegmentFault 一篇实测三款国产 Claw 的横评里，StepClaw 的缺点栏只有四个字：**编程能力弱**。另有第三方评测指出，Agent 在执行长路径任务时仍偶尔出现逻辑偏移或指令理解偏差。此外有实测反馈 **Windows 版本偶尔会出现任务卡住的情况**。

需要重申的是，同一篇横评对 KimiClaw 的缺点结论是「执行能力中等，复杂多步任务易中断」，对 ArkClaw 是「问 2-3 句才回一次，本地感弱」——这一代国产 Claw 普遍存在能力边界，StepClaw 只是把短板落在了编程这一格。

## 优势与短板

**最大的优势是它把「门槛」这件事彻底解决了。** 国产 Claw 的核心命题从来不是复刻一只龙虾，而是三层手术：换国产模型兜底解决合规与成本、套桌面端/微信入口降门槛、搭技能市场解决「装插件比装本体还难」。StepClaw 是这三层里做得最完整的一个——尤其是水产市场，它不是产品上线后补的运营动作，而是**阶跃在做龙虾之前就先发布的**。据 StepClaw 与水产市场负责人钟经纬的说法，春节期间做这个判断基于两点：OpenClaw 爆发后会有大量新用户遇到「不知道用来干嘛」的问题；OpenClaw 带来的资产类型（技能、经验、插件、频道、触发器）需要一个地方承载和分发。这个判断被后来的用户增长验证了。

**安全侧的投入也是实的。** 通用安全配置模板默认预装，覆盖身份认证、数据隔离与 Prompt Injection 防护；针对 Skill 投毒问题，水产市场用指令分析 + 代码分析双重防线识别提示词注入、偷读敏感文件、恶意外连、后门混淆，发现即拦截、不让上传；用户数据全部本地存储不上云不外传；遇到复杂情况可一键切回官方助手小跃接管。信通院首轮评测的六大观察里也明确指出，桌面端产品应强化最小权限和技能准入——StepClaw 的三级权限（自由/需确认/禁止）正对着这一条。

**短板同样清晰。** 第一是编程能力弱，这是第三方横评的直接结论，不是我的主观感受。第二是 token 经济学没被解决——这其实是整个 Claw 赛道的共性问题，行业观察者说得很直白：厂商靠免费不可能撑起这么大的消耗量，这也是最近云厂商到大模型创企纷纷给 token 提价的原因。第三是长路径任务漂移与 Windows 端偶发卡顿，属于工程成熟度问题，随版本迭代有望改善。

还有一点需要给读者祛魅：**「信通院首批认证」的含金量不宜过度解读。** 首轮共 7 家单位同批通过，包括华为、百度、智谱、阶跃、MiniMax、浩鲸科技等。它证明 StepClaw 达到了行业安全基线，但同赛道主要玩家几乎都拿到了，这是入场券不是护城河。

## 最终推荐

**强烈建议试的人：** 被原版 OpenClaw 环境配置劝退过、但确实想要一个能碰本机文件的 AI 助理的普通办公人群；工作里有大量流程确定的重复劳动——文件归档分类、定时数据汇总、邮件摘要、行业资讯监控、网页信息采集——这些正是它跑得最稳的场景；经常人不在电脑前但电脑上有活要干的人，微信遥控这个能力是刚需级别的；以及喜欢「养成感」、希望 AI 助手有形象有性格的用户，这块目前没有对手。

**建议谨慎的人：** 主要诉求是写代码、跑复杂多步开发任务的开发者，编程能力弱是明确结论，建议用专门的 AI 编程工具；对模型账单敏感、需要成本严格可预测的个人与小团队，先想清楚 Agent 模式下 token 消耗是普通对话的量级跃迁；需要把关键业务流程全权托管、不能容忍任务漂移的场景；以及 Linux 桌面用户——官方没有正式安装包。

**务实的用法：** 先从 Flash Mini（¥49/月，年付折合 ¥38/月）起步试水，跑两周看真实消耗再决定要不要升档，别一上来就冲 Flash Max。技能只装官方精选，第三方技能装之前看一眼创作者和评价。把它用在流程确定、失败成本低的活上——归档、汇总、监控、采集；而涉及代码、复杂决策或一次成型交付的任务，保持人工复核。另外强烈建议一开始就配好三级权限，敏感目录设为「需确认」或「禁止」，这是本地 Agent 的基本卫生习惯。

## 一句话总结
AStudio 适合想在 Windows/Mac 上用「国产算力 + 本地文件直连 + 可审计执行」把办公和 Coding 任务真正交付出去的中文用户；不适合追求极致多模型自由度、或想要成熟稳定产品的人——它太新，且好能力大多在付费墙后。

## 核心功能评测

**1. ACode Harness 执行内核（评分 4.5）**
AStudio 真正的护城河不是模型，而是把大模型意图转成可执行步骤的 Harness。它理解上下文、制定计划、调用工具、读写本地文件、运行命令，最后还自己校验一遍结果。搜狐实测星火 X2.5「能干活」——分析 61 页财报、定位代码 bug 都跑通了。过程全程可视，文件修改可看 Diff，关键操作需用户审批，把「AI 说完成」变成「用户能检查」。

**2. 双空间设计（评分 4.5）**
这是 AStudio 最聪明的结构取舍：日常空间处理资料整理、检索、报告、数据分析等轻办公（类似 ChatGPT）；项目空间绑定真实本地目录，Agent 在里面读代码、改代码、跑命令、验证产物。普通聊天工具的通病——临时问答和深度任务挤在同一条对话流导致上下文全混——被物理隔离开。guijiagi 实测建议先用非生产目录试用，摸清权限边界再挂代码主仓库。

**3. 三种执行模式（评分 4.3）**
简单任务直接执行；Plan 模式先出方案、你确认后再动手，适合超 10 步的复杂任务；Goal 模式给个目标它自主推进到完成，适合长链条一次性任务。门槛友好，但也需注意——给简单改文案开 Plan 反而多一层确认。

**4. 工具生态与深度调研（评分 4.2）**
内置翻译、OCR、PPT 等讯飞能力，插件市场接支付宝、高德、飞书，支持 MCP 与 Skills 扩展；web-search 插件能检索论文专利、生成可视化调研报告。验证过的工作流还能沉淀成「个人技能」下次复用，越用越懂你。短板是默认锁星火 X2.5，切 DeepSeek / 通义 / OpenAI 要自己在设置页填各家 Key，首配偏繁琐。

## 优势与短板

**优势**：第一，Harness 执行闭环是实打实的——不是聊天给建议，而是打开本地文件、跑命令、交付文档/网页/代码/研报并自校验，全程可看 Diff、可审批。第二，双空间把「轻问答」和「重项目」分开，避免上下文污染，项目空间真能读写本地目录。第三，全国产算力 + 端侧 4B 开源模型 + 100 万字上下文，Ollama 本地跑、断网可用，对数据主权敏感的用户是直接卖点。第四，价格够低，标准版连续包月 ¥16.8，且能接同花顺、天眼查等付费数据库，办公向实用性强。

**短板**：一是多模型切换要自己填 Key，默认仍锁星火 X2.5，对想自由换模型的开发者不够爽。二是新平台成熟度存疑——程序员实测 coding plan「人多接口很慢」，免费版体验受限、好能力给付费用户，高频使用大概率得掏钱。三是产品 2026-09-15 才发布，缺大规模长周期验证，Windows 客户端约 555MB，海外可用性有限。

## 最终推荐

**推荐给谁用**：
- 中文办公 + 轻度 Coding 用户，想让 AI 直接整理本地文档、生成报告/网页/代码的人——双空间 + Harness 闭环能明显省事。
- 有等保合规、数据不出境要求的政企团队——星火备案齐全，合规阻力比海外工具小。
- 预算敏感的个人——体验版免费、标准版连续包月 ¥16.8，先白嫖两周试真实项目再决定。

**不建议谁用**：
- 追求极致多模型自由度的开发者——默认锁星火，切模型要自己填 Key，不如 OpenClaw 自由。
- 想要成熟稳定产品的用户——它太新，长周期可靠性待观察，且好能力多在付费墙后。
- 纯 Mac 轻度用户且只想要聊天——日常空间约等于 ChatGPT，没必要为 Harness 装 555MB 客户端。

**上手建议**：先用体验版跑三个代表性任务（短文档、带文件分析、复杂项目），记录积分前后差值，再按并行需求与付费数据库需求选标准或高级版。项目空间首次连接务必用非生产目录。
